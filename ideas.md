# Zoophilist — Source Reference

The existing Zoophilist repository is the ground-truth specification for this setup phase. The immediate objective is to preserve its code and run its current experience without visual redesign or feature changes.

## Chosen Approach: Source-First Continuity

**Design Movement:** Fidelity-first implementation, where the existing repository defines the interface and interaction language.

**Core Principles:** Preserve the inherited structure; avoid speculative UI changes; establish a reliable local development environment; document deviations before introducing them.

**Color Philosophy:** Retain the repository’s existing color system. No new visual palette will be introduced during setup.

**Layout Paradigm:** Maintain the application’s current information architecture and routes exactly as supplied by the source.

**Signature Elements:** Existing branding, existing visual assets, and current interaction patterns remain the continuity markers.

**Interaction Philosophy:** No behavior changes in the setup phase. Interactions are verified, not reinvented.

**Animation:** Preserve existing motion and respect the application’s current preferences. No new animation is added during setup.

**Typography System:** Use the repository’s existing typography choices until a deliberate redesign brief is agreed.

**Brand Essence:** Zoophilist as currently expressed in the supplied source code; pragmatic, continuity-focused, and ready to extend.

**Brand Voice:** Preserve existing copy. Future changes should be explicit and feature-led rather than generic.

**Wordmark & Logo:** Preserve existing brand assets and favicon configuration until a future brief specifies an update.

**Signature Brand Color:** The existing repository determines the active signature color.
